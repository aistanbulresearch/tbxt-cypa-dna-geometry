# TBXT–CypA computational preprint

Read the [manuscript PDF](TBXT-preprint.pdf) or the [editable Word document](TBXT-preprint.docx). The [Markdown manuscript](manuscript.md), [figure legends](figures/captions.md) and [document build instructions](build/README.md) accompany both.

Start with the [evidence index](evidence.md) to find the source data behind a claim, including the earlier simulations, docking controls and integration results. The [structural supplement](../TBXT-revision/README.md) includes representative PDB/SDF structures, the paired DNA-placement calculations and the base-pair sensitivity check.

Figure 1A labels the penultimate C·G base pair at position 11 of the 12-base-pair reference duplex. The exceptional pocket-C placement overlaps the G·C base pair at position 2, at the other end. The reported overlap describes the geometry of this duplex. The probes’ binding, effect on DNA recognition and activity in chordoma remain experimentally unmeasured.

The manuscript includes the authors’ affiliations, corresponding-author contact, GPT-6.2 and software contribution statement, and funding and competing-interest declarations.
