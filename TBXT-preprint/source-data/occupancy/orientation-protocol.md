# Distinguishing T-box edge crossings from changes in the placement of CypA

Independently assess each simulation frame by its distance to six pre-existing protein placements. The references are the original monomer and independent reference-linker starts, each with covering, near and far geometries. Each reference contains the same full B probe. The query coordinates and the reference placements are superposed on a common TBXT core. Compute the root mean squared displacement of corresponding CypA Cα atoms (residues 2–163) in that TBXT frame, without further superposition of CypA. This distance responds to both rotation and translation. The source coordinates are chosen before looking at new trajectories.

For each frame return all six distances, the closest reference and the gap to the next closest. Record whether the frame moves between reference neighborhoods, how far CypA moves from the original pose, and the minimum distance reached to a different reference. Use these as descriptive orientation checks alongside the DNA footprint. A switch between nearest references is a Voronoi boundary crossing. It does not quantify the binding constant, and the six references are not an exhaustive catalog of solution states.
