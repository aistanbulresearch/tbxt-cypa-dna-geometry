# DeepTernary blind B/C readout

This readout is fixed before reviewing TBXT predictions. The results reader receives the independently prepared models and the reference DNA only after native model scoring. The prediction stage does not use the previously modelled three-body poses or DNA.

- Sort each pocket's native predicted P2 RMSD in ascending order, with the emitted numerical model identifier as the tie breaker. Score the first model, first five, first ten, and all 40. A surrogate score does not measure the true RMSD of these unknown structures. Retain rejected models in all denominators.
- Use each protein's own Cα reference frame to compare its experimental head coordinates with the predicted head coordinates. For TBXT use shared author positions 45–208, omitting 110–121. For CypA use 2–163. The primary head criterion is at most 3 Å heavy-atom RMSD for each end. Also tabulate 2 and 5 Å cutoffs. There is no additional head alignment. Atom order is checked against the probe chemical graph. For equivalent atom labels use symmetry permutations permitted by the full attached probe, while preserving both head assignments, stereochemistry and the tether. Record fixed-order and symmetry-aware values.
- Align TBXT to chain A of 8CDN over the common core. Exclude the terminal base on each end of strands C and D. Count each inner DNA heavy atom once if it lies strictly within 2.5 Å of any CypA heavy atom. Count distinct DNA nucleotide identifiers. A DNA-positive model has at least three such DNA atoms in at least two nucleotides. DNA is an overlay.
- Apply the preceding single-bound study's minimum heavy-atom gaps between proteins (≥2.6 Å), and between each protein and the full probe (≥2.2 Å). Record the three component distances and geometric overlap even in clashing models.
- Verify the output ligand's atom identity against the complete probe, compare the assigned stereocenters and stereo double bonds with those inferred from the exported 3D geometry, and require every covalent bond length to agree within 0.25 Å with the independent input probe conformer. This last threshold is a gross geometry check. Chemical integrity and steric filters are shown separately. The primary joint count requires two matched heads, steric clearance, acceptable ligand geometry and DNA overlay in the same model.
- Record first positive model ranks, distributions across score cutoffs and input/output checksums. These are counts of predictions from this procedure, not association probabilities or measures of affinity.
