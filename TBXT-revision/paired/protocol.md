# Paired rigid-duplex test

Protocol specified before the paired outcomes were calculated. Use all 200 post-start frames in the 11 continuation branches. Use the original two-step core registration to put frame coordinates into native 8CDN axes. Hold the entire snapshot fixed, including both ligand heads and the C-terminal helix. Restore the nearest periodic images of the intact ligand and CypA.

Use the same 8,193 DNA proposals for all branches. Proposal 0 reproduces the unperturbed 8CDN overlay. Proposals 1–8,192 use the six-dimensional Sobol sequence from the static analysis (scrambled, seed 6280). Translate the 486-heavy-atom duplex by up to ±2.5 Å per axis and rotate about its centroid using rotation-vector components of up to ±8° each. Preserve the row-vector convention of the original static sampler. Include the identity separately with each consecutive half when testing panel sensitivity.

Require the RMSD of the 20 interior C1′ atoms from their native positions to be ≤3 Å without superposition, and ≥70% recovery of native core Cα/interior C1′ pairs. A native pair has a separation ≤10 Å in 8CDN. A recovered pair is within its own native distance +2 Å in the actual frame. Use shared core residues 45–208, excluding 110–121. Apply whole-duplex heavy-atom minimum distances of ≥2.6, 2.2 and 2.6 Å to frame TBXT, intact probe and CypA respectively. Repeat with 3.0, 2.6 and 3.0 Å. The paired baseline removes only CypA. Define baseline failure as zero baseline placements, panel loss as a positive baseline with zero full placements, and retained fit as at least one full placement. Report partial reductions in counts separately. Check full masks are subsets of baseline masks, stricter masks are subsets of primary masks, and each union contains both halves. Evaluate native chain A plus the observed duplex as a receptor-only positive control, testing identity and panel at both clearances.

Select the passing pose with the smallest interior C1′ RMSD, breaking ties by proposal ID. Export a representative for each observed branch/status in the primary union; prefer frames with both partner-aligned crystal-head RMSDs ≤2 Å, then earliest replica and time. For baseline failure show the identity overlay, for panel loss show the closest baseline fit and for retained fit show the closest complete-assembly fit. This is a finite geometric search around a single rigid DNA duplex.
