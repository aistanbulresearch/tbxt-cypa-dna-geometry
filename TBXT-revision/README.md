# Structural supplement for the TBXT–CypA preprint

Use the [evidence index](../TBXT-preprint/evidence.md) to trace manuscript and figure results to the supplied files.

| Study | Unit tested | Comparison |
|---|---|---|
| [Paired DNA placement](paired/README.md) | One of 200 saved B-probe snapshots | Identical candidate duplex placements against TBXT and intact probe in each frame, with and without CypA. |
| [Helix sensitivity and static examples](structures/README.md) | One of 591 admissible static B/C assemblies | The same probe, CypA and DNA coordinates before and after restoring the resolved volume of TBXT residues 212–221. |
| [Base-pair register and endpoint sensitivity](base-pairs/README.md) | The same helix-inclusive assemblies and their registered 12-base-pair duplex | Requiring two distinct paired positions or cropping the duplex by one additional pair at each end. |

The trajectories contained no DNA. Each DNA pose in this supplement is a registered or sampled rigid duplex. A positive fit identifies one geometry that satisfies the specified filters. If a frame has no fit even after CypA removal, it provides no evidence for CypA-specific exclusion. The static intersecting examples intentionally superpose reference DNA onto CypA to show the clash.

The [figure legends](../TBXT-preprint/figures/captions.md) and plotting inputs accompany the supplement.
