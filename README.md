# Distinct cyclophilin A orientations around a modeled brachyury probe permit different fits of a single T-box duplex

Ozge A. Cavus and Aysegul Kuskucu

This computational study asks whether DNA and cyclophilin A (CypA) can fit alongside the same modeled brachyury (TBXT) probe. Two placements of the pocket-B probe illustrate the result. In one, the full reference duplex fits. In the other, CypA overlaps base pair 11 of 12. Binding of the intact probe and its effect on TBXT–DNA binding remain experimental questions.
